# 🛠️ Обработка пропусков: стратегия по типам данных

## 📌 Общее правило

> **Сначала анализируем, потом обрабатываем.** Для каждого столбца смотрим % пропусков и природу данных.

```python
# Код для анализа пропусков
missing = df.isnull().sum()
missing_pct = (missing / len(df) * 100).round(2)
missing_df = pd.DataFrame({'Количество': missing, 'Процент': missing_pct})
display(missing_df[missing_df['Количество'] > 0].sort_values('Процент', ascending=False))
```

## 🎯 Стратегии по типам признаков

### 1️⃣ **Числовые признаки (total_area, lat, lon, price)**

| Ситуация | Стратегия | Когда применять |
|----------|-----------|-----------------|
| Пропусков < 5% | Удалить строки | Самый простой способ |
| Пропусков 5-20% | Медиана/Среднее | Для симметричных распределений |
| Пропусков > 20% | Предсказать через KNN или ML-модель | Если признак критичен |
| Есть логическая связь | Вычислить из других фичей | `price_per_sqm = price_rub / total_area` |

**Конкретные примеры:**
```python
# Площадь - медиана по району и типу дома
df['living_area'] = df.groupby(['district', 'building_type'])['living_area']\
                      .transform(lambda x: x.fillna(x.median()))

# Координаты - медиана по району
df['lat'] = df.groupby('district')['lat'].transform(lambda x: x.fillna(x.median()))

# Высота потолков - по типу дома
ceiling_defaults = {
    'khrushchev': 2.5,
    'stalin': 3.0,
    'panel': 2.65,
    'brick': 2.7,
    'monolith': 2.8,
    'modern_panel': 2.7
}
df['ceiling_height'] = df['ceiling_height'].fillna(df['building_type'].map(ceiling_defaults))
```

---

### 2️⃣ **Категориальные признаки (district, okrug, building_type)**

| Ситуация | Стратегия | Пример |
|----------|-----------|--------|
| Мало пропусков (< 5%) | Мода (самое частое значение) | `building_type` → `'panel'` |
| Много пропусков | Отдельная категория `"unknown"` | Сохраняем информацию о пропуске |
| Можно вывести из других | Восстановить по связям | `district` из `lat/lon` через reverse geocoding |

```python
# Округ можно восстановить из района (есть справочник соответствий)
district_to_okrug = {
    'Arbat': 'CAO', 'Tverskoy': 'CAO', 'Khamovniki': 'CAO',
    # ... остальные 125 районов
}
df['okrug'] = df['okrug'].fillna(df['district'].map(district_to_okrug))

# Пропуски в renovation → 'no_renovation' (самое частое)
df['renovation'] = df['renovation'].fillna('no_renovation')

# Если пропусков много — отдельная категория
df['building_type'] = df['building_type'].fillna('unknown')
```

---

### 3️⃣ **Булевы признаки (has_balcony, subsidized_mortgage)**

```python
# Самое безопасное — предположить отсутствие
df['has_balcony'] = df['has_balcony'].fillna(False)

# Или отдельный флаг "неизвестно"
df['has_balcony_unknown'] = df['has_balcony'].isna().astype(int)
df['has_balcony'] = df['has_balcony'].fillna(False)
```

---

### 4️⃣ **Временные признаки (date_posted, building_year)**

```python
# Дата публикации - удалить строки с пропуском (это же ключевой признак!)
df = df.dropna(subset=['date_posted'])

# Год постройки - медиана по типу дома
df['building_year'] = df.groupby('building_type')['building_year']\
                        .transform(lambda x: x.fillna(x.median()))
```

---

### 5️⃣ **Составные признаки (сложные случаи)**

#### 🔥 **`metro_distance_min`** — самый частый пропуск
```python
# Стратегия: предсказать по расстоянию до станции
# 1. Если есть координаты квартиры и станции - вычислить через Haversine
# 2. Если нет - взять медиану по району

df['metro_distance_min'] = df['metro_distance_min'].fillna(
    df.groupby('district')['metro_distance_min'].transform('median')
)

# Дополнительно: создать бинарный признак "нет данных о метро"
df['metro_distance_unknown'] = df['metro_distance_min'].isna().astype(int)
```

#### 🔥 **`price_per_sqm`** — если пропущен, но есть `price_rub` и `total_area`:
```python
# Просто вычислить!
df['price_per_sqm'] = df.apply(
    lambda row: row['price_rub'] / row['total_area'] 
    if pd.isna(row['price_per_sqm']) and not pd.isna(row['price_rub']) 
    else row['price_per_sqm'],
    axis=1
)
```

| Признак | Тип | % пропусков (ожидаемый) | Стратегия |
|---------|-----|-------------------------|-----------|
| `total_area` | float | <1% | Удалить строки |
| `living_area`, `kitchen_area` | float | 5-15% | Медиана по rooms + district |
| `building_year` | int | 5-10% | Медиана по building_type |
| `ceiling_height` | float | 20-30% | Default по building_type |
| `has_balcony` | bool | 10-20% | False + флаг unknown |
| `renovation` | str | 30-40% | `'no_renovation'` |
| `metro_distance_min` | int | 15-25% | Вычислить из координат / медиана по району |
| `district` | str | <2% | Восстановить из lat/lon |
| `okrug` | str | <2% | Из district (справочник) |
| `price_rub` (target) | int | 0% | **Удалить строки с пропуском!** |

## ⚡ Универсальный пайплайн для вашего проекта

```python
def preprocess_real_estate(df):
    """Обработка пропусков для датасета недвижимости Москвы"""
    
    df = df.copy()
    
    # 1. Удаляем строки без целевой переменной
    df = df.dropna(subset=['price_rub'])
    
    # 2. Восстанавливаем локацию
    df['okrug'] = df['okrug'].fillna(df['district'].map(district_to_okrug))
    
    # 3. Числовые признаки
    df['living_area'] = df.groupby(['rooms', 'district'])['living_area'].transform(
        lambda x: x.fillna(x.median())
    )
    df['kitchen_area'] = df['kitchen_area'].fillna(df['kitchen_area'].median())
    df['ceiling_height'] = df['ceiling_height'].fillna(
        df['building_type'].map(ceiling_defaults)
    )
    
    # 4. Категориальные
    df['renovation'] = df['renovation'].fillna('no_renovation')
    df['building_type'] = df['building_type'].fillna('unknown')
    
    # 5. Флаги пропусков (важно для ML!)
    df['living_area_missing'] = df['living_area'].isna().astype(int)
    df['metro_distance_unknown'] = df['metro_distance_min'].isna().astype(int)
    
    # 6. Числовые остатки
    df['metro_distance_min'] = df.groupby('district')['metro_distance_min'].transform(
        lambda x: x.fillna(x.median())
    )
    
    return df
```

## 💡 Важные советы

### ✅ **Делайте:**
1. **Создавайте флаги пропусков** — модель может извлечь из них информацию (например, пропуск в renovation часто означает "без ремонта")
2. **Сохраняйте логику данных** — высота потолков зависит от типа дома, а не от района
3. **Валидируйте после импьютации** — проверьте распределения до и после

### ❌ **Не делайте:**
1. **Не удаляйте строки с целевой переменной** (`price_rub`) — только при её пропуске
2. **Не заполняйте средним** для skewed данных (площадь, цена) — используйте медиану
3. **Не удаляйте целые столбцы** без анализа — даже 30% пропусков можно обработать
